TASK DESCRIPTION
================================================================================
Building a streaming indicator precomputation system for IBKR trading pipeline.
Goal: pre-compute indicators matching live/streaming conditions (vol_pct_complete=1.0,
no future lookahead) so models train on data matching inference. System uses
`precompute_streaming_indicators.py` (multiprocessing, day-based) to save Parquet
files, fed into `master_pipeline.py` via `--indicators-file` flag. The simulator's
indicators must exactly match the precomputed indicators used for training.

This is a LIVE PAPER TRADING SIMULATOR — simulates exactly what would happen in
live trading, bar-by-bar, no lookahead.

Critical constraint: positions must be capped so notional (shares × price) never
exceeds $1M capital. Risk 1% of $1M = $10K max risk per trade, but share count
must also respect capital limits.
