## CURRENT STATUS — READY TO RUN

### To launch paper trading:
1. Ensure IBKR TWS or Gateway is running (port 7497 confirmed listening)
2. In VS Code: **F5** → select **"Trading: Paper 5m"**
3. Or from terminal:
   ```
   .\.venv\Scripts\python.exe -m trading.runner --model models\rf_vwap_stop0.75_20260218_192628.pkl --paper --bar-size 5m --log-level DEBUG
   ```

### What happens on launch:
1. Connects to IBKR paper (127.0.0.1:7497)
2. Qualifies TSLA contract
3. Fetches ~200 historical 5-min bars for indicator warm-up
4. Subscribes to keepUpToDate 5-min bars
5. On each new bar: compute indicators → model.predict_proba → if prob ≥ 0.50, submit bracket order (MKT entry + stop + VWAP target via OCA)
6. EOD flatten 5 min before close (15:55 ET)
7. Ctrl+C → flatten all → disconnect

### First run may reveal:
- Feature mismatch (model expects features that `calculate_core_indicators` doesn't produce, or vice versa) — will show as `None` values in feature vector, signal skipped
- The model's `stop_atr` from metadata will be auto-used (0.75 for this model)
- Market hours matter — outside RTH, no bars arrive for `useRTH=True`
