## The Math Behind It

### Single Trade Example (0.50 ATR):

```
Entry: $250.00
ATR: $2.50 (1% of price)
Stop: 0.50 ATR = $1.25 below entry

Long Setup:
  Entry: $250.00
  Stop: $248.75 (risk $125)
  Target: VWAP at $253.56 (reward $356)
  R:R: 3.02:1
  
  If Win (43.8%): +$356 - $3 costs = +$353
  If Loss (56.2%): -$125 - $3 costs = -$128
  
  EV = 0.438 × $353 + 0.562 × (-$128)
     = $154.61 - $71.94
     = $82.67 per trade
```

### Yearly Math:

```
8,245 trades × $82.67 avg = $681,684
Add variance/slippage ≈ $762K actual
```
